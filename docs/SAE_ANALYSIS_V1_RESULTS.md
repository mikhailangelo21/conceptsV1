The canonical full run is [`runs/sae_analysis_v1_core-5fe3b13cdf8a`](../runs/sae_analysis_v1_core-5fe3b13cdf8a/); the smoke run is [`runs/sae_analysis_v1_smoke-335c7349e926`](../runs/sae_analysis_v1_smoke-335c7349e926/). ## Question and design

We asked whether Qwen3-1.7B-Base residual states (`H`) and its layer-specific Qwen-Scope Top-100 SAE codes (`F`) carry ordered quality information, whether compact reductions preserve it, and whether the apparent geometry survives changes in wording and entity family. The fixtures have author-written ordinal, hue and factorial labels. They are controlled prompts, not human perceptual ratings. Entity and final-token readouts were analysed separately; a shared text/token-position vector enters a global PCA once even when it has multiple case labels. SAE feature IDs are meaningful only inside their own checkpoint.

The predeclared fitting rule admits train entity families, familiar wording, nonnumeric cases and training factorial combinations. Training alone fits PCA, candidate feature selection, text vectorization, ridge probes and UMAP; validation selects ridge strength; test remains frozen. Standard t-SNE and certain extended embeddings are explicitly descriptive all-splits analyses. The [saved configuration](../configs/sae_analysis_v1.json), `identity.json`, `provenance.json`, `sample_ids.json` and method registry in the run record seeds, source hashes, software and fitting IDs. The collection manifest is authoritative about available layers.

The source collection requested 14,500 unique main readouts and 4,805 trace positions per layer. Nine zero-based layers (0, 1, 3, 7, 11, 15, 19, 23, 27) have complete sparse main and trace codes. Layer 2 has 7,424/14,500 main codes and no completed trace; 18 layers have no sparse codes. Raw residual states exist separately. The core profile uses the nine complete layers; it does not silently fill gaps. Activity scans use all encoded readouts on those layers. Expensive analyses use up to 1,600 eligible train, 500 validation, 500 test and 500 withheld/numeric train-challenge readouts per readout type, with IDs saved. A smaller fixed balanced cohort supports nonlinear methods.

## Main findings

1. **The prompt bank contains decodable quality information.** Across 234 matched layer/readout/task evaluations from 14 supported quality tasks with at least 10 familiar-wording test records and two entity families, the median test Spearman correlation was **0.63 for H** and **0.40 for F**. The median paired H−F difference was **0.16**; H scored higher in **78%** of these comparisons. These 234 scores repeatedly use the same prompts and mostly only two independent test families. They are diagnostic comparisons, not 234 independent replications. See `predictions/metrics.csv` and the report's held-out ordering chart.

2. **Prompt wording is a serious shortcut.** On the exact same selected readouts, a train-fitted unigram/bigram prompt-text control had median familiar-test Spearman **0.46** across 26 readout/task cells; length alone had median **−0.06** across 23 evaluable cells. Across the 234 layer/readout/task comparisons with matching text scores, H exceeded text by a median **0.15** and F was below text by a median **0.04**. Text may directly state the authored quality level, so this control does not isolate a semantic mechanism. These are paired descriptive differences, with reused tasks and families. See `baselines/metrics.csv`, saved TF-IDF vectorizers and the lexical-control chart. Historical V3 summary scores are on different denominators and are not pooled with these values.

3. **Low-variance information still matters.** Relative to each full representation's test probe, 16 train-fitted PCs reduced median test Spearman by **0.31 for H** and **0.20 for F** across the matched evaluations. Even 64 PCs had median drops of **0.12** and **0.08** respectively. At the layer-11 final readout, 64 PCs explained about **96%** of H and **89%** of F *training variance*. Median relative rank-64 reconstruction error over all analysed layers/readouts was H **0.23** on train versus **0.59** on test, and F **0.33** on train versus **0.59** on test. The frozen reducers retain training variance much better than held-out vectors. PCA variance is therefore an incomplete guide to useful held-out quality information. See `linear/pca_summary.csv`, `linear/partitioned_reconstruction.csv` and `predictions/additional_ranks.csv`.

4. **Transfer and selectivity are limited.** Across 225 matched layer/readout/task comparisons with adequate familiar and withheld-wording test records, H median Spearman fell from **0.64 to 0.24** and F from **0.39 to 0.10**. Median within-task drops were **0.31** and **0.29**. Train-fitted SAE contrast directions correctly signed roughly **81%** of training and **69%** of test contrasts on representative layers. For held-out factorial examples at layer 11/final, the target projection exceeded every off-target projection in a median **36%** of 17 domain/quality summaries. Each such factorial summary has only **one** test entity family. This is evidence against a strong claim of clean, independently varying factors in this fixture bank, not a population estimate. See `predictions/transfer.csv`, `contrasts/direction_transfer.csv` and `factorial/summary.csv`.

5. **A tidy 2D layout would overstate the geometry.** On original-space bounded cohorts, median TwoNN dimensions were **2.63 (H)** and **3.41 (F)**; k-neighbour MLE at k=20 gave **5.06** and **6.58**. Local PCA changes with neighbourhood size. These are method- and density-dependent complexity diagnostics, not counts of psychological dimensions. The nonlinear fidelity tables report local trustworthiness separately from sampled global distance-rank correlation. UMAP is fitted on eligible train and transforms held-out points; t-SNE is fitted to all sampled splits and cannot be compared as an equally held-out method. Seed and parameter sensitivity is saved. See `dimension/*`, `embeddings/*` and `extended/nonlinear_sensitivity.csv`.

6. **Hue ordering is partial, with no established circle.** At layer 11/final, F placed the authored near colour closer than the far colour in **141/240 (59%)** prespecified original-code triplets. Validation was **23/48 (48%)** and test **33/48 (69%)**; those triplets reuse only two entity families in each held-out split. Circular sine/cosine probe scores and angular errors are saved, but the present evidence does not establish a stable circular manifold. Optional original-space persistent homology was recorded as unavailable because `ripser` is not installed; no loop claim is based on a UMAP picture. See `hue/triplets.csv` and `predictions/metrics.csv`.

## Other completed diagnostics

The activity scan found a median of 4,682 observed features at entity positions, 2,078 at final positions and 11,354 across token traces per complete layer. These counts describe this sample and do not identify globally dead features. Median relative SAE reconstruction error was 0.37 at entity and 0.23 at final positions. Bounded coactivation matrices include binary joint frequency, lift/phi and activation-value correlation. The 6,840-row feature catalogue joins checkpoint hashes, activity and reconstruction statistics, train-selected quality associations, wording differences and representative activating prompts. Candidate meanings remain hypotheses. `linear/component_interpretation.csv` records leading F-PC positive/negative loadings and descriptive associations with quality, wording, entity family and prompt length. Decoder-direction PCA is stored separately from activation PCA.

The pipeline also saved aligned exact-decoder `H`, `H_hat` and `E=H−H_hat` samples; cross-layer CKA on matched vectors; matched `ΔH`/`ΔF` contrasts and train-fitted contrast directions; token-role trace summaries; row/feature-scale sensitivity; and observational links to saved V3 comparison scores split by natural-continuation versus A/B format. Diffusion maps and a separate supervised PLS check ran on bounded cohorts. PaCMAP, TriMap, PHATE and `ripser` were skipped with recorded package-availability reasons. Nonnumeric ordinary probes do not fit a physical-value calibration from withheld numeric challenges, so physical-unit prediction is unresolved.

## Verification and rerunning

From the project root with its virtual environment, these commands reproduce the workflow. A new core run can receive a different content-addressed ID if the source or configuration has changed; set `ANALYSIS_RUN` to the new path printed by the core command if that happens.

```bash
source .venv/bin/activate
pytest -m 'not integration' -q
qd sae-analyze run --profile smoke
qd sae-analyze run --profile core
ANALYSIS_RUN="runs/sae_analysis_v1_core-5fe3b13cdf8a"
qd sae-analyze enrich --run-dir "$ANALYSIS_RUN"
qd sae-analyze optional-methods --run-dir "$ANALYSIS_RUN"
qd sae-analyze context --run-dir "$ANALYSIS_RUN"
qd sae-analyze reconstruction --run-dir "$ANALYSIS_RUN"
qd sae-analyze baselines --run-dir "$ANALYSIS_RUN"
qd sae-analyze report --run-dir "$ANALYSIS_RUN"
```

The core and smoke run states, enrichment and context stages are complete. The non-integration suite passes **53 tests** (one integration test deselected). The self-contained `report.html` is built from source-backed `artifact.json` and its chart database using the Data Analytics portable builder, whose validation, packaging and desktop/narrow-viewport checks passed. Exportable scientific figures are in the [tracked SVG set](../reports/sae_analysis_v1/plots/) and the full run's [`plots/`](../runs/sae_analysis_v1_core-5fe3b13cdf8a/plots/). For the exact builder command and the full file map, see [the methods document](SAE_ANALYSIS_V1.md).

The strongest unresolved step is independent replication: more entity families, unseen natural wording and ideally external or human-rated stimuli. Completing the 28-layer SAE encoding would also require more storage; the current analysis correctly reports its missing layers and never triggers new collection automatically.
