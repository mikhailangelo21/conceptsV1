## Main evidence

| Question | Result | Where to verify it | What it supports and limits |
|---|---|---|---|
| Can a probe order familiar five-level descriptions? | Mean test Spearman rho `0.964` across 14 properties; mean absolute error `0.121` on the 0–1 design scale. | [linear_metrics.csv](runs/quality_suite_v3_laptop-88fad55b46b0/linear_metrics.csv), [graded.csv](reports/quality_suite_v3_findings/graded.csv) | Strong decodability in a controlled wording. Static and word-based baselines are also strong, so it is not enough to show an abstract axis. Each property has two test families. |
| Does that transfer to held-out paraphrases? | Mean rho `0.721`; mean error `0.316`. Size drops from `0.985` to `0.295` rho; hardness from `0.935` to `0.148`. | Same files; compare `plain` and `paraphrase` partitions. | Wording is a major source of instability. Correlation and calibration can fail differently. |
| Is entity–property binding present beyond a word inventory? | Familiar same-word binding pairs have rho `0.873` for each of 14 properties; all familiar matched swaps have correctly signed predicted changes. Word-inventory baselines are constant across the swap. | [binding.csv](reports/quality_suite_v3_findings/binding.csv), [paired_contrasts.csv](runs/quality_suite_v3_laptop-88fad55b46b0/paired_contrasts.csv) | Positive contextual binding evidence. Only one independent test family and eight binary rows per property; the repeated rho reflects ties and sample structure. Paraphrase is weaker. |
| Do nuisance edits leave the readout fixed? | Equal-property mean absolute changes: clause reordering `0.138` familiar / `0.241` paraphrase; irrelevant edits `0.064` / `0.144`. A genuine adjacent level increase changes the familiar prediction by `0.201` on average. | [paired.csv](reports/quality_suite_v3_findings/paired.csv), [paired_summary.csv](runs/quality_suite_v3_laptop-88fad55b46b0/paired_summary.csv) | Nuisance variation can be appreciable relative to a real level change. These are distinct contrast families, not paired ratios of identical items. |
| Does the model answer comparison questions consistently? | Across matched test questions for six qualities: natural continuation accuracy `87.5%` familiar / `75.0%` paraphrase; A/B accuracy `63.5%` / `59.4%`. | [matched_behavior.csv](reports/quality_suite_v3_findings/matched_behavior.csv), [behavior_scores.csv](runs/quality_suite_v3_laptop-88fad55b46b0/behavior_scores.csv) | Answer format matters in these examples. Each quality/wording has four underlying comparisons from one test family; A/B has four counterbalances per comparison. This is constrained likelihood scoring, not free generation. |
| Can probes report physical values? | The simple numerical-text baseline has lower range-normalized error for six of eight properties. Hidden-state probes win on speed and temperature only. | [numeric_overall.csv](reports/quality_suite_v3_findings/numeric_overall.csv), [numeric_challenges.csv](runs/quality_suite_v3_laptop-88fad55b46b0/numeric_challenges.csv) | Ordinal information does not imply a well-calibrated physical-unit code. Each physical test has one independent family. Challenge mixes vary. |
| Does hue form a robust circular readout? | At selected block 16 final token, angular test error is `56.3°` for numeric descriptions and `71.1°` for colour words. Near/far triplet order is `19/24` versus `12/24`. | [hue.csv](reports/quality_suite_v3_findings/hue.csv), [circular_neighborhoods.csv](runs/quality_suite_v3_laptop-88fad55b46b0/circular_neighborhoods.csv) | Partial numeric hue structure. The six hue subspace training contrasts are 0°/360° invariance pairs, so their SVD rank cannot establish hue dimensionality. |
| Do multiple attributes transfer together? | Selected joint probes have mixed familiar-wording performance. Some retain ordering under a new wording and combination yet have errors near or above a full design-scale unit. | [multioutput_metrics.csv](runs/quality_suite_v3_laptop-88fad55b46b0/multioutput_metrics.csv), [factorial.csv](reports/quality_suite_v3_findings/factorial.csv) | Ranking can remain high while calibration fails. Hardest partitions often have just 2–10 rows from one test family. |

Lexical generalization is mixed and based on provisional authored ratings. Familiar lexical rho is negative for speed (`−0.775`), loudness (`−0.632`) and pitch (`−0.667`); mass reaches `1.0` on only three held-out concepts. See [lexical.csv](reports/quality_suite_v3_findings/lexical.csv) and the full report for all qualities. This is not a comparison with independent human norm data.

## Claims this experiment does not establish

The run does not demonstrate universal quality axes, precise intrinsic subspace dimension, human-perceptual alignment, physical measurement competence, robust transfer to unrelated language or real object categories, or causal control of answers. `causal_gate.json` records zero interventions; `nonlinear.json` records no nonlinear restarts. Predictive factorial selectivity is observational. Strong Spearman correlations should always be read alongside MAE and the independent-family count.

The previous size-only pilot selected block 23 and reported held-out-template ridge rho about `0.721` on 12 test groups. V3's stronger familiar-wording scores cannot be read as a paired improvement because the datasets and labels changed. The pilot report is included under [runs/pilot_m2-792030855aa5](runs/pilot_m2-792030855aa5/); the V3 comparison is [comparison_to_original_pilot.json](runs/quality_suite_v3_laptop-88fad55b46b0/comparison_to_original_pilot.json).

## Most useful next work

Replicate the binding finding with more independent entity families and independently authored syntax; use a final untouched test set. Add a competent unit-aware baseline and separate validation objectives for ordering and numerical calibration. Replace hue invariance contrasts with hue-changing contrasts for subspace analysis. Only after a probe transfers reliably should intervention tests assess whether editing the state selectively changes model answers. The full report's final section explains these priorities.
